# 项目能力总览

本文档根据当前代码仓库中的实际实现整理，重点说明项目已经具备的能力，以及仍处于预留或未接通状态的模块。

## 能力状态说明

- `已可用`：已经存在命令入口和处理逻辑。
- `实验性`：已经有实现，但更偏向增强能力、AI 编排或外部集成。
- `预留/未接通`：存在命令定义或目录骨架，但当前处理逻辑未完整启用。

## 平台与基础能力

### 已可用

- 基于 NoneBot2 的插件化机器人架构。
- 已配置适配器：
  - OneBot V11
  - OneBot V12
  - QQ 官方适配器
- 已接入插件能力：
  - `nonebot-plugin-alconna`：统一命令解析
  - `nonebot-plugin-orm`：数据库模型与持久化
  - `nonebot-plugin-localstore`：本地数据目录管理
  - `nonebot-plugin-apscheduler`：定时任务
  - `nonebot-plugin-htmlrender`：HTML 渲染成图片
  - `nonebot-plugin-status`：运行状态能力
  - `nonebot-plugin-waiter`：多轮交互等待

### 实验性

- 支持多模型配置的 LLM 客户端能力，可区分是否支持多模态、函数调用。
- 支持文档转图片、OCR、二维码、Markdown 转图片、文件上传 COS 等扩展工具。

## 用户与组织管理

### 已可用

- 用户信息查询：
  - `我的信息`
  - 可查看用户、教师、学生的绑定状态和基础资料
- 多平台账号绑定：
  - `绑定用户`
  - 通过 token 在不同机器人平台间绑定同一用户
- 用户/教师/学生注销：
  - `注销`
- 学校与学院管理：
  - `添加学校`
  - `添加学院`
  - 当前带有管理员扩展校验
- 班级管理：
  - `添加班级`
  - `查询班级`
  - `加入班级`
  - `退出班级`
  - `删除班级`
  - 支持群与班级绑定
- 学生信息维护：
  - `修改学生信息`

### 预留/未接通

- `teacher` 模块目录已存在，但当前没有实际教师管理命令或处理逻辑。

## 教务与身份认证

### 预留/未接通

- 存在教务登录入口：
  - `登录教务系统`
  - `教务系统登录`
  - `登录教务`
  - `登录`
- 当前实现只有统一接口和学校登录抽象，默认仍会返回“暂不支持该学校”。
- 说明仓库已经为学校级登录适配预留扩展点，但尚未落具体学校实现。

## 日常班级业务能力

### 已可用

- 课表管理：
  - `添加课表`
  - `删除课表`
  - `查询课表`
  - `分享课表`
  - `设置当前周`
- 课表增强能力：
  - 每周自动推进当前周
  - 早上定时推送个人或班级课表
- 作业/任务收发：
  - `创建任务`
  - `查询任务`
  - `提交任务`
  - `导出任务`
  - `删除任务`
- 作业能力细节：
  - 当前实际流程以学生侧创建、提交、导出为主，教师创建仍提示“暂不支持创建”
  - 学生可提交文件/图片
  - 可查看已提交/未提交名单
  - 可将提交内容打包导出
- 请假管理：
  - `请假`
  - `查询请假`
  - `设置请假推送`
  - `删除请假`
- 请假能力细节：
  - 支持文字加图片的请假信息输入
  - 支持班干部/教师视角查看请假
  - 支持向指定班干部推送请假
- 学生检索与群内协作：
  - `查找学生`
  - `at`
  - 支持按多个条件检索学生
  - 可将结果渲染为图片

### 预留/未接通

- 通知模块存在命令定义：
  - `创建通知`
  - `查询通知`
  - `删除通知`
- 但当前 `notice` 模块主体处理逻辑被注释，暂不应视为已可用能力。

## AI 与智能体能力

### 已可用

- 自然语言会话编排：
  - 被 `@` 机器人或直接触发消息后进入 AI 对话处理流程
- 会话管理：
  - `清空聊天`
  - 支持按用户维度维护会话上下文
- 命令帮助系统：
  - `help`
  - `帮助`
  - 能把各插件声明的帮助信息汇总并展示

### 实验性

- 已实现的 Agent 能力包括：
  - `HelperAgent`：检索命令帮助
  - `VisionAgent`：理解图片内容
  - `FileAgent`：解析文档文件
  - `SummaryAgent`：长对话总结
  - `ExtractAgent`：提取聊天上下文关键信息
  - `RagAgent`：对接 RagFlow 进行知识检索
  - `AutoTaskAgent`：将自然语言转换为命令任务
- 文本生成能力：
  - `文本创作`
  - `生成文本`
- 图片生成能力：
  - `图片生成`
  - `生成图片`
  - `图生图`
  - `图生成`
- AI 辅助命令编排：
  - 通过 LLM 将用户输入转成一个或多个机器人命令
  - 能结合命令帮助系统来约束生成结果

## 校园与外部信息能力

### 已可用

- 校园位置查询：
  - `校园地图`
  - 通过模板渲染返回地点展示结果
- 抖音视频解析：
  - 自动识别抖音分享链接
  - 支持无水印视频或封面图返回

## 文件、媒体与工具链能力

### 已可用

- 文档转图片：
  - 支持 Word、PPT、PDF 转图片
- OCR 相关模型与推理能力：
  - 已集成 ONNX Runtime
  - 已内置 OCR 模型资源
- 云对象存储上传：
  - 可将图片、文件上传到 COS 并回传访问链接
- 渲染与格式化：
  - 支持 HTML 模板渲染
  - 支持 Markdown 转图片
  - 支持二维码生成与解析

### 已完成 skill 化拆分

- `document-to-image`
  - 统一封装 Word、PPT、PDF 转图片能力
  - 当前被文件解析 Agent 复用
- `ocr`
  - 统一封装验证码识别与多行文本 OCR 能力
  - 底层复用 DBNet + CRNN 模型
- `qr-code`
  - 统一封装二维码生成与解析能力
  - 当前被任务导出、校园地图、文稿下载等流程复用
- `markdown-to-image`
  - 统一封装 Markdown 到 HTML、Markdown 到图片、HTML 到图片能力
  - 当前被 AutoGPT 长文本回退和文本创作预览复用

## 当前能力边界

- 本项目已经具备“班级管理 + 作业流转 + 课表 + 请假 + AI 对话增强”的主体能力。
- AI 能力不是独立产品层，而是与命令系统和帮助系统深度耦合，用于把自然语言转为具体机器人行为。
- 部分目录仍是预留结构，不应该在文档、宣传或对外说明里按“已完成模块”描述，主要包括：
  - `src/managers/teacher`
  - `src/plugins/notice`
  - `src/managers/auth` 中尚未具体落地的学校登录实现
