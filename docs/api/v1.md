# API V1

## 获取所有命令

```
GET /api/v1/commands
```

返回所有可用命令的列表。

```json
{
    "helpers": [
        {
            "command": "校园地图",
            "description": "查询学校某个楼的位置。",
            "ai_description": "当用户需要去什么地方，查询什么位置时调用这个命令来帮助用户，而不是AI去捏造一些不存在的地方或路线。",
            "tags": [],
            "roles": ["user"],
            "params": [
                {
                "name": "position",
                "description": "您想知道学校哪个地方的位置",
                "mode": "+"
                }
            ],
            "aliases": [],
            "example": [
                {
                    "role": "user",
                    "content": "校园地图 position"
                }
            ]
        }
    ]
}
```
