# API V1

## 获取所有命令

```
GET /api/v1/commands
```

返回所有可用命令的列表。

```json
{
    "helpers": [
        {
            "command": "我的信息",
            "description": "查看自己的信息,是否为教师或学生"
        },
        {
            "command": "查询任务",
            "description": "通过任务ID或名称查询，当不携带名称时显示所有任务"
        }
    ]
}
```
