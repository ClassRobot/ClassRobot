# 项目能力总览

本文档根据当前代码仓库中的实际实现整理，重点说明项目已经具备的能力，以及仍处于预留或未接通状态的模块。

## 能力状态说明

- `已可用`：已经存在命令入口和处理逻辑。
- `实验性`：已经有实现，但更偏向增强能力、AI 编排或外部集成。
- `预留/未接通`：存在命令定义或目录骨架，但当前处理逻辑未完整启用。

## 平台与基础能力

### 已可用

- 基于 NoneBot2 的插件化机器人架构。
- 已配置适配器：
  - OneBot V11
  - OneBot V12
  - QQ 官方适配器
- 已接入插件能力：
  - `nonebot-plugin-alconna`：统一命令解析
  - `nonebot-plugin-orm`：数据库模型与持久化
  - `nonebot-plugin-localstore`：本地数据目录管理
  - `nonebot-plugin-apscheduler`：定时任务
  - `nonebot-plugin-htmlrender`：HTML 渲染成图片
  - `nonebot-plugin-status`：运行状态能力
  - `nonebot-plugin-waiter`：多轮交互等待

### 实验性

- 支持多模型配置的 LLM 客户端能力，可区分是否支持多模态、函数调用。
- 支持文档转图片、OCR、二维码、Markdown 转图片、文件上传 COS 等扩展工具。

- 用户/教师/学生注销：
  - `注销`
- 学校、学院、专业与组织管理：
  - `添加学校`
  - `修改学校`
  - `删除学校`
  - `添加学院`
  - `修改学院`
  - `删除学院`
  - `添加专业`
  - `修改专业`
  - `删除专业`
  - `添加组织`
  - `修改组织`
  - `删除组织`
  - 当前带有管理员扩展校验
- 组织结构查询：
  - `查询组织架构`
  - `查询组织`
- 教师身份管理：
  - `查询教师信息`
  - `修改教师信息`
  - 支持补录教师归属学校、学院，以及查询教师管理班级
- 班级管理：
  - `导入班级`
  - `添加班级`

  - `退出班级`

- 班级管理细节：

  - 支持 Excel 批量导入学生与班级数据
- 学生信息维护：
  - `查询学生信息`
  - `修改学生信息`
- 组织成员管理：

  - `退出组织`

  - `分享课表`

## AI 与智能体能力

### 已可用

- 自然语言会话编排：
  - 被 `@` 机器人或直接触发消息后进入 AI 对话处理流程
- 会话管理：
  - `清空聊天`
  - 支持按用户维度维护会话上下文
- 命令帮助系统：
  - `help`
  - `帮助`
  - 能把各插件声明的帮助信息汇总并展示

### 实验性

- 已实现的 Agent 能力包括：
  - `HelperAgent`：检索命令帮助
  - `VisionAgent`：理解图片内容
  - `FileAgent`：解析文档文件
  - `SummaryAgent`：长对话总结
  - `ExtractAgent`：提取聊天上下文关键信息
  - `RagAgent`：对接 RagFlow 进行知识检索
  - `AutoTaskAgent`：将自然语言转换为命令任务
- 当前 RAG 处理方式：
  - 先由 `ExtractAgent` 从对话中提取结构化问题
  - 再由 `RagAgent` 调用 RagFlow 完成检索问答
  - 返回答案时可附带引用材料图片，便于直接在聊天平台展示
- 文本生成能力：
  - `文本创作`
  - `生成文本`
- 图片生成能力：
  - `图片生成`
  - `生成图片`
  - `图生图`
  - `图生成`
  - 当前支持文本生图、图片加文本生图
  - 当前命令底层已收敛到 `image-generation` skill
- AI 辅助命令编排：
  - 通过 LLM 将用户输入转成一个或多个机器人命令
  - 能结合命令帮助系统来约束生成结果
- 当前消息主链路已经按“平台入口 -> 权限上下文 -> 消息流水线 -> Agent -> 数据访问 -> 回复”进行收敛，详见 [消息处理流程](../guides/message-processing-flow.md)

### 已可用

- 校园位置查询：
  - `校园地图`
  - 通过模板渲染返回地点展示结果
- 抖音视频解析：

  - 支持无水印视频或封面图返回

## 文件、媒体与工具链能力

### 已可用

- 文档转图片：
  - 支持 Word、PPT、PDF 转图片
- OCR 相关模型与推理能力：
  - 已集成 ONNX Runtime
  - 已内置 OCR 模型资源
- 云对象存储上传：
  - 可将图片、文件上传到 COS 并回传访问链接
- 渲染与格式化：
  - 支持 HTML 模板渲染
  - 支持 Markdown 转图片
  - 支持二维码生成与解析
- 图片生成链路：
  - 已可通过 `image-generation` skill 调用底层生图接口
  - 当前命令层会在生成后上传 COS，并回发图片消息
- 文件理解链路：
  - 已可通过 `FileAgent` + `document-to-image` skill 对文档内容做多模态理解
  - 适合摘要、抽取、阅读理解类场景

### 预留/未接通

- 文档样式改写与重新导出：
  - 当前还没有“读取 docx 结构 -> 修改样式 -> 保存新 docx”的完整运行时链路
  - 如果后续需要“按论文格式排版”这类能力，建议新增 `document-reader` 和 `document-formatter` skill

### 已完成 skill 化拆分

- `document-to-image`
  - 统一封装 Word、PPT、PDF 转图片能力
  - 当前被文件解析 Agent 复用
- `ocr`
  - 统一封装验证码识别与多行文本 OCR 能力
  - 底层复用 DBNet + CRNN 模型
- `qr-code`
  - 统一封装二维码生成与解析能力
  - 当前被任务导出、校园地图、文稿下载等流程复用
- `markdown-to-image`
  - 统一封装 Markdown 到 HTML、Markdown 到图片、HTML 到图片能力
  - 当前被 AutoGPT 长文本回退和文本创作预览复用
- `image-generation`
  - 统一封装文生图、图生图能力
  - 当前被 `图片生成` 命令复用

## 当前能力边界

- 本项目已经具备“班级管理 + 作业流转 + 课表 + 请假 + AI 对话增强”的主体能力。
- AI 能力不是独立产品层，而是与命令系统和帮助系统深度耦合，用于把自然语言转为具体机器人行为。
- 部分目录仍是预留结构，不应该在文档、宣传或对外说明里按“已完成模块”描述，主要包括：
  - `src/plugins/notice`
  - `src/managers/auth` 中尚未具体落地的学校登录实现
