# 课表模块

`src/features/curriculum/` 负责用户课表的录入、查询、分享与当前周设置。

## 模块作用

这个模块主要处理个人课表相关能力：

- 添加自己的课表
- 删除自己的课表
- 查询自己的课表或指定班级课表
- 分享课表给其他用户
- 设置当前周

当前命令入口定义在 `commands.py`，命令处理逻辑集中在 `__init__.py`，依赖解析在 `depends.py`，周期与节次解析在 `util.py` 与 `interval.py`。

## 当前命令

### `添加课表`

- 作用：新增一条个人课表记录
- 权限：`UserRole.user`
- help 目录：`普通用户命令`
- Agent：默认可见，但当前仍由 matcher 直接处理，不走统一 service 执行器
- 典型用法：

```text
添加课表 1-12 1 1-2 高等数学 一教101 张老师
```

### `删除课表`

- 作用：删除自己创建的课表
- 权限：`UserRole.user`
- help 目录：`普通用户命令`
- 风险等级：`high`
- 典型用法：

```text
删除课表 12 13 14
```

### `查询课表`

- 作用：查询自己的课表，或按班级和天数偏移查询
- 权限：`UserRole.user`
- 别名：`查看课表`、`课表查询`、`我的课表`
- help 目录：`普通用户命令`
- 典型用法：

```text
查询课表
查询课表 软件1班
查询课表 软件1班 1
查询课表 1
```

### `分享课表`

- 作用：生成分享 ID，或通过分享 ID/班级名称获取课表
- 权限：`UserRole.user`
- 别名：`分享课程表`、`分享课程`、`共享课程`、`共享课表`、`绑定课表`
- help 目录：`普通用户命令`

### `设置当前周`

- 作用：设置自己的当前周；具备班级课表管理能力时可指定班级 ID
- 权限：`UserRole.user`
- help 目录：`普通用户命令`

## 权限说明

- 课表命令统一面向系统内用户开放
- 是否能删除、分享、修改具体课表，由依赖与业务逻辑继续校验
- 命令可见性与权限元数据来自 `commands.py`

## 代码结构

- `commands.py`
  命令声明、参数元数据、help 元数据
- `__init__.py`
  matcher 处理入口
- `depends.py`
  课表相关依赖解析
- `util.py`
  课表范围解析与工具函数
- `interval.py`
  课表周期相关运行逻辑
- `schema.py`
  课表相关模型与结构

## 扩展建议

- 如果后续新增“班级课表管理”“导入课表”等命令，优先继续放在这个业务模块下
- 当命令数量明显增加时，可按 `query.py`、`write.py`、`share.py` 拆分 `commands/` 与 `services/`
- 如果后续要开放给 Agent，优先先抽出稳定的 service handler，再接入统一执行器
