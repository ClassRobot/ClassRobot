# 教师身份模块

`src/features/teacher/` 负责当前账号的教师信息查询与修改。

## 模块作用

这个模块聚焦当前用户的教师身份：

- 查询教师信息
- 修改教师信息
- 在必要时为普通用户补建教师身份

## 当前命令

### `查询教师信息`

- 别名：`教师信息`、`我的教师信息`
- 作用：查询当前账号绑定的教师信息与所管理班级
- 权限：`UserRole.teacher`
- help 目录：`教师身份命令`

### `修改教师信息`

- 别名：`修改教师`、`设置教师信息`
- 作用：修改教师姓名、学校、学院；如果当前账号还未绑定教师身份，可在校验通过后自动创建
- 权限：`UserRole.user`、`UserRole.teacher`
- 排除：`UserRole.student`
- help 目录：`教师身份命令`
- 风险等级：`medium`

典型用法：

```text
查询教师信息
修改教师信息 姓名=张老师 学校=测试大学 学院=计算机学院
```

## 权限说明

- 已经是教师的用户可以查询和维护自己的教师信息
- 普通用户可以通过该命令进入教师身份创建/补录流程
- 学生身份默认被排除，避免师生身份冲突

## 代码结构

- `commands.py`
  命令声明、权限元数据、帮助信息
- `__init__.py`
  matcher 处理入口
- `services.py`
  已接入统一执行器的教师查询服务与教师信息字段校验逻辑
- `presenters.py`
  教师信息展示渲染

## Agent 说明

- `查询教师信息` 已接入统一执行器，适合 Agent 查询
- 修改教师信息当前仍更适合用户直接触发

## 扩展建议

- 若后续增加教师身份审批、转移学院归属等能力，可继续拆出 `permissions.py`
