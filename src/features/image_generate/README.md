# 图片生成模块

`src/features/image_generate/` 负责把用户的图生图、文生图等图片生成请求接入系统。

## 模块作用

该模块用于处理以下场景：

- 纯文字生成图片
- 根据已有图片继续编辑
- 图片加文字描述的复合生成需求

## 当前命令

### `图片生成`

- 别名：`生成图片`、`图生图`、`图生成`
- 权限：`UserRole.user`
- help 目录：`普通用户命令`
- Agent：当前不直接开放给 Agent
- 风险等级：`medium`

典型用法：

```text
图片生成 一只穿西装的猫
图生成 [图片] 给这个人物换成蓝色衣服
生成图片 [图片] 把背景改成教室
```

## 权限说明

- 面向普通用户开放
- 命令本身依赖真实图片消息输入，因此当前主要面向用户直发

## 代码结构

- `commands.py`
  命令声明与帮助元数据
- `__init__.py`
  matcher 处理入口
- `util.py`
  图片生成辅助逻辑

## 扩展建议

- 如果后续加入“图片生成历史”“多模型切换”，可继续在本模块拆出 `services.py` 与 `schemas.py`
