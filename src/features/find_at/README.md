# 查找与艾特模块

`src/features/find_at/` 负责在班级或同学范围内按条件查找学生，并支持基于查找结果执行 at。

## 模块作用

该模块聚焦“按条件搜索人”：

- 根据姓名、班级、寝室等条件查找学生
- 根据同样的搜索条件直接 at 对应用户

## 当前命令

### `查找学生`

- 别名：`查询学生`、`搜索学生`
- 作用：按多个关键词搜索自己班级内的学生或同学
- 权限：`UserRole.teacher`、`UserRole.student`
- help 目录：`学生身份命令`、`教师身份命令`
- 典型用法：

```text
查找学生 张三
查找学生 李四 王五
查找学生 1班.张三
查找学生 1-123.张三
```

### `at`

- 别名：`艾特`
- 作用：先查找，再对命中的用户执行 at
- 权限：`UserRole.teacher`、`UserRole.student`
- help 目录：`学生身份命令`、`教师身份命令`

## 权限说明

- 仅学生和教师可用
- 具体能搜索到哪些对象，仍由业务逻辑按班级归属判断
- 命令元数据统一定义在 `commands.py`

## 代码结构

- `commands.py`
  命令声明、别名、帮助元数据
- `__init__.py`
  matcher 逻辑入口
- `depends.py`
  查找所需依赖注入
- `util.py`
  可搜索字段定义与搜索辅助逻辑

## 扩展建议

- 如果后续新增“查找教师”“查找班干部”“批量 at”能力，仍然应收敛在这个模块
- 若搜索条件越来越复杂，可以拆出 `schemas.py` 与 `services.py`
