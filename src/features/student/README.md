# 学生身份模块

`src/features/student/` 负责当前账号的学生信息查询与修改，也提供管理员、学院负责人和班级管理教师使用的学生档案管理命令。

## 模块作用

这个模块聚焦“当前用户绑定的学生身份资料”：

- 查询当前学生信息
- 修改当前学生信息
- 按管理范围查询、添加、修改、删除学生档案

## 当前命令

### `查询学生信息`

- 别名：`学生信息`、`我的学生信息`
- 作用：查看当前账号绑定的学生信息、班级、学号和附加资料
- 权限：`UserRole.student`
- help 目录：`学生身份命令`

### `修改学生信息`

- 别名：`修改学生`、`设置学生信息`
- 作用：按 `键=值` 方式修改学生资料
- 权限：`UserRole.student`
- help 目录：`学生身份命令`
- 风险等级：`medium`

典型用法：

```text
查询学生信息
修改学生信息 姓名=张三 宿舍=1-203 手机号=13800000000
```

### 管理型学生档案命令

- `查询学生档案 [学生ID]`
- `添加学生 <用户ID> <班级ID> <学生姓名>`
- `修改学生档案 <学生ID> <字段=值>...`
- `删除学生 <学生ID>`

这些命令用于管理别人或班级内的学生档案，不等同于 `修改学生信息`。

## 权限说明

- 仅学生身份可用
- 只能修改当前账号绑定的学生资料
- 字段可修改范围由业务逻辑进一步限制
- 学生不能通过 `修改学生信息` 自行设置班干部或班助/助教岗位
- 管理型学生档案命令需要管理员、学院负责人或班主任/辅导员具备目标范围权限
- 班级岗位统一由 `src/features/classes` 的 `设置学生岗位` / `取消学生岗位` 维护

## 代码结构

- `commands.py`
  命令声明、别名、帮助元数据
- `__init__.py`
  matcher 处理入口
- `services.py`
  已接入统一执行器的查询服务
- `presenters.py`
  学生信息卡片渲染

## Agent 说明

- `查询学生信息` 已有统一执行器 handler，更适合 Agent 读取
- `查询学生档案` 已接入统一执行器，适合 Agent 在管理权限下读取学生档案
- 修改类命令当前仍主要面向用户直接触发

## 扩展建议

- 如果后续学生资料字段继续增长，可补 `schemas.py`
- 如果后续要增加“学生身份创建/解绑”流程，应与 `user`、`classes` 模块联动设计
