# 学生身份模块

`src/features/student/` 负责当前账号的学生信息查询与修改。

## 模块作用

这个模块聚焦“当前用户绑定的学生身份资料”：

- 查询当前学生信息
- 修改当前学生信息

## 当前命令

### `查询学生信息`

- 别名：`学生信息`、`我的学生信息`
- 作用：查看当前账号绑定的学生信息、班级、学号和附加资料
- 权限：`UserRole.student`
- help 目录：`学生身份命令`

### `修改学生信息`

- 别名：`修改学生`、`设置学生信息`
- 作用：按 `键=值` 方式修改学生资料
- 权限：`UserRole.student`
- help 目录：`学生身份命令`
- 风险等级：`medium`

典型用法：

```text
查询学生信息
修改学生信息 姓名=张三 宿舍=1-203 手机号=13800000000
```

## 权限说明

- 仅学生身份可用
- 只能修改当前账号绑定的学生资料
- 字段可修改范围由业务逻辑进一步限制

## 代码结构

- `commands.py`
  命令声明、别名、帮助元数据
- `__init__.py`
  matcher 处理入口
- `services.py`
  已接入统一执行器的查询服务
- `presenters.py`
  学生信息卡片渲染

## Agent 说明

- `查询学生信息` 已有统一执行器 handler，更适合 Agent 读取
- 修改类命令当前仍主要面向用户直接触发

## 扩展建议

- 如果后续学生资料字段继续增长，可补 `schemas.py`
- 如果后续要增加“学生身份创建/解绑”流程，应与 `user`、`classes` 模块联动设计
