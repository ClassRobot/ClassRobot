# 其它插件

`src/others/` 用来放置不适合直接归入主业务插件、但仍然需要作为系统能力保留的模块。

当前这里更适合承载下面两类内容：

- 实验性功能
  - 已有可运行入口，但暂时还没有完全并入主业务目录
- 外部集成或独立能力
  - 例如图像生成、第三方接口适配等

## 当前目录

- `image_generate/`
  - 图片生成命令入口与平台回发逻辑

## 放置建议

- 如果能力已经成为稳定的校园业务功能，优先迁到 `src/plugins/` 或 `src/managers/`
- 如果能力本质上是可复用执行能力，底层实现应继续沉到 Skill 或工具层
- `src/others/` 不建议长期堆放“未来也没人知道归哪”的临时模块
