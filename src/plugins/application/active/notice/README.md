# 通知模块

`src/plugins/application/active/notice/` 预留给通知创建、查询、删除与定时通知能力。

## 当前状态

这个模块已经有基础命令声明和部分数据结构，但当前用户侧流程仍处于未完全开放状态。

也就是说：

- 命令 matcher 已存在
- 统一命令元数据已部分接线
- 但实际业务处理逻辑当前仍以注释或未完全收口状态存在
- 因此当前不应把这些命令当作已稳定可用能力看待

## 当前命令

### `创建通知`

- 别名：`定时`、`转发`
- 当前状态：命令入口存在，但业务处理逻辑尚未正式开放

### `查询通知`

- 当前状态：命令已接入统一命令注册，但 `helper_visible=False`
- 含义：暂不在 `help` 中向普通用户展示

### `删除通知`

- 当前状态：命令已接入统一命令注册，但 `helper_visible=False`
- 含义：暂不在 `help` 中向普通用户展示

## 权限说明

- 目前这个模块不应视为稳定的用户公开功能
- 文档保留的目的是说明该模块已经存在，但仍处于开发中或待恢复状态

## 代码结构

- `commands.py`
  命令声明
- `__init__.py`
  历史 matcher 逻辑，目前主要是注释保留
- `depends.py`
  通知相关依赖
- `schema.py`
  通知结构模型
- `prompt.py`
  通知相关提示词
- `manage.py`、`util.py`
  通知业务辅助逻辑

## 维护约定

- 如果后续恢复通知功能，应先补全 README 中的命令可用性、权限、使用方式与测试说明
- 在功能正式开放前，不要把本模块当成已完成 feature 对外宣传
- 通知发送必须通过 `src.platform.messaging` 统一投递，不要在通知模块里直接判断 OneBot、QQ、wxclaw 等具体平台
- wxclaw 当前只通过统一投递层支持文本私聊通知；群组通知和多媒体通知需要等平台能力明确后再扩展
