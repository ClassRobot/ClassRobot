# 用户模块

`src/plugins/application/active/user/` 负责用户账号自身的基础能力，包括查看个人信息、跨平台绑定与注销。

## 模块作用

这个模块处理账号级能力：

- 查询当前账号信息
- 跨平台绑定同一个用户
- 注销账号或角色身份
- 接收 `token=...` 绑定确认消息

## 当前命令

### `我的信息`

- 别名：`个人信息`、`用户信息`
- 作用：查看自己的账号信息、当前角色、是否为管理员、教师、学生等
- 权限：`UserRole.user`
- help 目录：`普通用户命令`
- 已接入统一执行器，适合 Agent 查询

### `绑定用户`

- 别名：`绑定平台`、`绑定`、`换绑平台`、`关联平台`
- 作用：生成临时 token，用于把不同平台上的机器人账号绑定到同一个系统用户
- 权限：`UserRole.user`
- help 目录：`普通用户命令`
- 执行模式：交互式命令

### `注销`

- 别名：`删除账号`、`账号注销`
- 作用：注销当前用户、教师或学生身份，并删除相关数据
- 权限：`UserRole.user`
- help 目录：`普通用户命令`
- 风险等级：`high`
- 执行模式：交互式命令

### `token`

- 作用：接收绑定 token 并完成平台绑定
- 当前状态：内部配套命令，不展示在 help 中
- 使用方式：通常由用户在另一平台把 `token=xxxxxx` 直接发送给机器人

## 使用示例

```text
我的信息
绑定用户
注销 用户
token=xxxxxx
```

## 权限说明

- `我的信息`、`绑定用户`、`注销` 面向普通用户开放
- 实际注销哪个角色，还会继续校验当前账号是否已经绑定教师或学生信息
- `token` 是绑定流程配套入口，不算普通帮助命令

## 代码结构

- `commands.py`
  命令声明、权限元数据、帮助元数据
- `__init__.py`
  matcher 处理与多轮确认流程
- `services.py`
  用户信息查询统一执行器逻辑
- `presenters.py`
  用户信息卡片渲染

## Agent 说明

- `我的信息` 已接入统一执行器，适合 Agent 读取当前用户状态
- `绑定用户`、`注销` 都涉及确认和副作用，当前主要面向用户直接触发

## 扩展建议

- 如果后续增加“修改昵称”“修改头像”“安全设置”，继续收敛到这个模块
- 若用户身份流程继续复杂化，可拆出 `commands/security.py` 与 `commands/profile.py`
