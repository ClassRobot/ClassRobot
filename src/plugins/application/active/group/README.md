# 群组与组织架构模块

`src/plugins/application/active/group/` 负责学校、学院、专业、组织等组织架构管理，以及用户加入或退出组织。

## 模块作用

这个模块对应的是“组织结构”和“组织成员关系”：

- 管理学校、学院、专业
- 管理学院负责人岗位
- 管理学校下的组织
- 查询学校整体组织架构
- 让学生或教师加入、退出组织

这里的“组织”是系统内业务实体，不等同于平台原始群号。

## 当前命令

### 管理类命令

以下命令统一为管理员命令：

- `添加学校`
- `修改学校`
- `删除学校`
- `添加学院`
- `修改学院`
- `删除学院`
- `添加专业`
- `修改专业`
- `删除专业`
- `添加组织`
- `修改组织`
- `删除组织`
- `设置学院负责人`
- `取消学院负责人`

共同特征：

- 权限：`UserRole.admin`
- help 目录：`管理员命令`
- 写操作风险较高，删除类命令通常带确认流程

### 查询类命令

#### `查询组织架构`

- 别名：`组织架构`、`学校架构`
- 作用：查看学校、学院、专业、班级与组织的结构
- 权限：公共命令
- help 目录：`公共命令`

#### `查询组织`

- 别名：`组织列表`
- 作用：查询组织列表，也可进一步查看组织成员
- 权限：公共命令
- help 目录：`公共命令`

### 成员关系命令

#### `加入组织`

- 作用：以学生或教师身份加入指定组织
- 权限：`UserRole.student`、`UserRole.teacher`
- help 目录：`学生身份命令`、`教师身份命令`

#### `退出组织`

- 作用：以学生或教师身份退出指定组织
- 权限：`UserRole.student`、`UserRole.teacher`
- help 目录：`学生身份命令`、`教师身份命令`

## 权限说明

- 管理类命令仅管理员可用
- 学院负责人岗位由 `CollegeTeacher` 表表达，授予和撤销仍然仅管理员可用
- 组织成员类命令要求当前账号已经绑定学生或教师身份
- 是否能对某个学校、学院、组织执行操作，由业务逻辑继续校验

## 代码结构

- `commands.py`
  命令声明、权限元数据、help 元数据
- `__init__.py`
  matcher 处理入口
- `services.py`
  删除确认、组织身份解析、更新字段解析等共享逻辑
- `constants.py`
  组织类型、字段映射等常量

## 使用示例

```text
添加学校 测试大学 北京
添加学院 测试大学 计算机学院
添加专业 测试大学 计算机学院 软件工程
设置学院负责人 测试大学 计算机学院 8
查询组织架构
加入组织 测试大学 学生会 学生 干事
```

## 扩展建议

- 如果后续要新增更多学院岗位，优先扩展 `CollegeTeacherRole` 和对应 service 权限，不要把学院内岗位塞进全局 `UserRole`
- 如果组织相关命令继续增长，可拆成 `commands/manage.py`、`commands/query.py`、`commands/member.py`
