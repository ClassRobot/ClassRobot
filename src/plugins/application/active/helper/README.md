# Help 模块

`src/plugins/application/active/helper/` 负责用户侧 `help` 命令入口，以及启动时构建帮助目录。

## 模块作用

这个模块只负责两件事：

- 提供 `help` / `帮助` 命令
- 在启动时收集所有 feature 的帮助元数据，并绑定统一鉴权链路

真正的帮助模型、分组规则、角色过滤逻辑位于 `src/platform/helper/`。

## 当前命令

### `help`

- 别名：`帮助`
- 作用：
  - 不带参数时，展示当前身份可用的命令目录
  - 带命令名称时，展示该命令的详细帮助
- 权限：公共命令
- help 目录：`公共命令`
- Agent：不对 Agent 开放

典型用法：

```text
help
help 查询班级
帮助
```

## 权限说明

- `help` 自身是公共命令
- 但展示结果会根据当前用户身份动态过滤
- 学生能看到学生可用命令和继承的普通用户命令
- 教师能看到教师可用命令和继承的普通用户命令
- 管理员能看到管理员命令

## 代码结构

- `commands.py`
  `help` 命令声明和帮助元数据
- `__init__.py`
  `help` matcher 处理逻辑与启动时 bootstrap

## 扩展建议

- 如果未来要支持“按标签筛选帮助”“导出命令目录”，优先在 `src/platform/helper` 扩展能力，再回到这个入口模块接线
