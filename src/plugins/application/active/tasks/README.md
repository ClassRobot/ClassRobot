# 任务模块

`src/plugins/application/active/tasks/` 负责班级任务、作业的创建、提交、导出、删除与查询。

## 模块作用

这个模块用于围绕“任务/作业收集”开展工作：

- 创建任务
- 学生提交任务
- 查询任务完成情况
- 删除任务
- 导出任务提交文件

## 当前命令

### `提交任务`

- 别名：由“上传/提交 + 作业/任务”组合生成
- 作用：向指定任务提交文件、图片等内容
- 权限：`UserRole.student`
- help 目录：`学生身份命令`
- 执行模式：交互式命令

### `创建任务`

- 别名：由“创建/发布 + 作业/任务”组合生成
- 作用：创建新的任务
- 权限：`UserRole.student`
- help 目录：`学生身份命令`

### `删除任务`

- 别名：由“删除/撤销 + 作业/任务”组合生成
- 作用：按名称或 ID 删除任务
- 权限：`UserRole.student`、`UserRole.teacher`
- help 目录：`学生身份命令`、`教师身份命令`

### `导出任务`

- 别名：由“导出/下载 + 作业/任务”组合生成
- 作用：打包并导出已提交任务文件
- 权限：`UserRole.student`、`UserRole.teacher`
- help 目录：`学生身份命令`、`教师身份命令`

### `查询任务`

- 别名：由“查询/查看 + 作业/任务”组合生成
- 作用：查询指定任务或任务列表
- 权限：`UserRole.student`、`UserRole.teacher`
- help 目录：`学生身份命令`、`教师身份命令`

## 使用示例

```text
创建任务 第一周实验报告
提交任务 第一周实验报告 [文件]
查询任务
查询任务 第一周实验报告
导出任务 第一周实验报告
删除任务 第一周实验报告
```

## 权限说明

- 当前实现中，教师查询和导出能力可用，但教师创建任务仍有限制
- 具体能操作哪个任务，依赖当前班级、任务归属和任务管理对象继续判断

## 代码结构

- `commands.py`
  命令声明、别名、权限元数据
- `__init__.py`
  matcher 多轮交互与任务操作流程
- `util.py`
  任务文件、任务管理器等工具逻辑

## 扩展建议

- 如果后续引入教师发布任务、批改或提醒，建议拆分为 `commands/query.py`、`commands/write.py`
- 如果要对 Agent 开放，优先先抽稳定 service handler
