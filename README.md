# 班级机器人

## 项目简介

本项目是一个班级机器人，可以帮助老师和同学们更好地管理班级事务，降低工作负担。

同时该项目的交互可以做到跨平台使用，什么你说为什么可以跨平台？那是`nonebot-plugin-alconna`给我的自信（大概）。

## 项目结构

- `src/`: NoneBot 插件与路由
- `utils/`: 共享配置、模型、LLM 和工具能力
- `resources/`: prompts、HTML 模板、OCR 模型等非源码资源
- `scripts/`: 辅助脚本
- `migrations/`: 数据库迁移
- `docs/`: 说明文档

更详细的目录约定见 `docs/project-structure.md`。
